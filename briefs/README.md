# briefs/

Точки входа для owner-сессий baser. **Здесь нет знания** — только маршрут: роль, зона, ссылки на канон.

Источник правды: канон и контракты — в knowledger, задачи и статусы — в tasker. Бриф устаревает молча,
узел KB — нет, поэтому в брифе не должно быть ничего, что можно прочитать по ссылке (`kb:ADR-14`, `kb:ADR-10`).

## Как пользоваться

1. Открой свой бриф — он назовёт роль, зону и обязательный к прочтению канон.
2. Прочитай канон ДО первого действия. Не угадывай (`kb:BRAIN-5`).
3. Веди работу в своём узле tasker, не в файлах репо.

## Порядок чтения для любой owner-сессии baser

| Что | Где | Зачем |
|---|---|---|
| Онбординг агент-сессии | `kb:BRAIN-5` | роль, дисциплина, git-гейты |
| Роль продукта baser | `kb:BASER-4` | почему фундамент не подстраивается под потребителя |
| **Контракт материализации** | `kb:BASER-5` | **интерфейс, против которого ты пишешь код** |
| Рыночный канон движка | `kb:BASER-3` | обоснование каждого пункта контракта, с источниками |
| Канон-стек | `kb:BASER-2` | на чём строим (Nx, публичный npm) |
| Шов config↔прогон | `kb:ADR-21` | что НЕ твоё: прогон, креды, CI |
